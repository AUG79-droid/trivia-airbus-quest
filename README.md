# Sustainability Quest — ES

Juego de tablero colaborativo de sostenibilidad aplicada con **48 preguntas situacionales**, ocho en cada una de seis categorías.

## Ámbitos
1. Ecodiseño y ciclo de vida.
2. Operaciones y energía.
3. Circularidad y materiales.
4. Cadena de suministro y cumplimiento.
5. Evidencia y gobernanza.
6. Riesgos y resiliencia.

## Dinámica
Una a cuatro personas pueden tirar el dado, elegir rutas, responder preguntas con feedback razonado y conseguir las seis insignias. El recorrido termina con un reto final. Se conserva el funcionamiento del tablero y la puntuación; las categorías y preguntas se han reemplazado para ampliar el alcance.

**Nota sobre el progreso:** dado que el significado de las seis insignias ha cambiado, esta versión guarda las nuevas partidas con una clave v3 distinta. Las partidas anteriores no se migran ni se borran automáticamente del navegador.

## Carácter formativo
Los casos son ficticios y sirven para aprender a valorar evidencias, requisitos y alternativas. No constituyen procedimientos aprobados de Airbus, autorizaciones técnicas, certificaciones ni resultados medidos de desempeño.
